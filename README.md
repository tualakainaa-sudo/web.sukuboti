# Web Suku Boti NTT + Adat Bena
Website statis siap GitHub Pages.

Isi:
- Suku Boti: Halaika, Uis Neno/Uis Pah, Ume Kbubu, Lopo, tenun.
- Bagian khusus Kampung Adat Bena: Ngadhu, Bhaga, Sa'o, ruang megalitik dan Reba.
- Galeri foto dan etika berkunjung.
- Responsive untuk HP dan laptop.

Catatan: Kampung Adat Bena berada di Ngada, Flores dan bukan bagian dari Suku Boti di Timor Tengah Selatan. Keduanya ditampilkan sebagai dua kekayaan budaya NTT yang berbeda.

GitHub Pages:
1. Buat repository.
2. Upload isi folder ini.
3. Settings > Pages.
4. Deploy from a branch > main > /(root).
5. Save.
